# ZerOSINT Frontend

A cyber-themed frontend for passive, legal open-source intelligence workflows. It is designed for analysts, students, and blue teams exploring relationships between public identifiers such as usernames, email addresses, and domains.

> This repository contains the user interface. Results should only use lawful, publicly available data and must not be treated as verified facts without independent confirmation.

## Features

- Search entry point for usernames, emails, and domains
- Investigation dashboard flow
- Entity relationship visualisation with D3
- Responsive terminal-inspired interface
- Clear ethical-use messaging

## Tech stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- D3.js

## Run locally

Requirements: Node.js 18–20.

```bash
git clone https://github.com/naziulsiam/zerosint-frontend.git
cd zerosint-frontend
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```

## Responsible use

Use ZerOSINT only for authorised, defensive, educational, or investigative purposes. Respect privacy, applicable law, website terms, and data-source restrictions.
